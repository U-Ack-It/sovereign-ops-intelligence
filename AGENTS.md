Build a local-first operations intelligence platform for:
1. Vendor Intelligence
2. Estate Command
3. Naples HomeWatch Command

## Security rules
- No cloud in MVP
- No biometric data
- No hidden surveillance
- No autonomous physical control
- No Google Maps scraping
- No spam automation
- Manual review required

## Coding rules
- Small files
- Simple functions
- Beginner-readable code
- Explain before major changes
